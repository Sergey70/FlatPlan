# FlatPlan

**[Открыть редактор квартиры](https://sergey70.github.io/FlatPlan/)** · **[Галерея интерьеров](https://sergey70.github.io/FlatPlan/?view=gallery)** · [Репозиторий](https://github.com/Sergey70/FlatPlan)

Интерактивный 3D/2D-редактор квартиры по предоставленному файлу `.plan` версии 3. Работает на компьютере и телефоне без регистрации. Стены, проёмы, мебель и детали можно выбирать, перемещать, поворачивать, менять их размеры и материалы, сохранять варианты и переносить проект через JSON.

## Исходные планировки

По умолчанию открыт вариант **«Квартира — кухня и две комнаты»**: правый план из файла, с ванной. Помещение **21,43 м² — кухня**, **13,55 м² — спальня**. Три отдельные схемы санузла сохранены. Предметов вне контуров в новом файле нет. Все расстановки доступны во вкладке **Варианты → Сохранённые расстановки**.

| Вариант | Содержимое |
| --- | --- |
| Квартира | Правый план квартиры: 37 участков стен, 4 оконных/французских проёма, 5 дверных проёмов, 56 предметов |
| Санузел — вариант 1 | 10 участков стен, 1 дверь, 7 предметов |
| Санузел — вариант 2 | 11 участков стен, 1 дверь, 6 предметов |
| Санузел — вариант 3 | 12 участков стен, 1 дверь, 4 предмета |

Перенесены числовые координаты стен, включая скосы стыков, толщины, высоты, контуры комнат, положения и размеры проёмов, подоконников, габариты и повороты предметов. Единицы файла — сантиметры; в редакторе — метры. Высота стен **2,70 м**. Обычные окна полного плана имеют ширину **1,90 м**, высоту **1,50 м**, подоконник **0,85 м**. Дополнительное окно на верхнем наружном фасаде из прежнего предположения по фотографии удалено: в новом файле его нет.

Мебель показана условными объёмными моделями с габаритами из файла. Для предметов без записанной вертикальной высоты используются явно описанные значения. Материалы, форма отдельных деталей и освещение иллюстративные. Двери показаны полотнами, открытыми на 45°, и дугами открывания на плане. Направления и смещение относительно стены перенесены из файла и сверены со схемой. В 3D полотна видны при выключенном срезе стен. Полное соответствие исходному плану означает соответствие его геометрии, а не подтверждение фактических обмеров квартиры. [Точность и допущения](PLAN_ASSUMPTIONS.md).

## Обновление сохранённого проекта

PLAN-011 исправляет кухонный диван: спинка расположена у перегородки, сиденья обращены в кухню. Координаты, габариты и угол дивана из файла сохранены. Исправляются только нетронутые смещения спинки и трёх сидений в текущей сцене и сохранённых вариантах. Пользовательские позиции, размеры, материалы и остальные предметы сохраняются.

PLAN-010 сверяет проект с экспортом от 8 сентября, 15:35: обновляет точные стыки стен и проёмы, расширенную тумбу, подписи помещений и отображение дверей/кроватей. Для PLAN-008/009 изменения переносятся по полям: вручную изменённые позиции, размеры и материалы сохраняются. Если новая геометрия несовместима с отредактированной стеной, эта стена целиком остаётся прежней. Исходная расстановка «Предметы вне контуров» удаляется только при неизменённой геометрии; изменённый вариант сохраняется. Последующие перезагрузки сохраняют правки; удалённые исходные варианты не создаются повторно. Для просмотра точной исходной схемы используйте кнопку открытия исходного плана в разделе **Объекты**.

Для проектов, которые ещё не переходили на `.plan`, сохраняется полный резервный вариант **«До обновления по файлу .plan»** и добавляются четыре актуальные исходных расстановок.

Ограничение — 30 вариантов. Если для обновления не хватает места, текущий проект остаётся доступен, автосохранение приостанавливается и появляется сообщение. Скачайте JSON, удалите ненужные варианты и повторите открытие исходного плана кнопкой в разделе **Объекты**.

Прямые ссылки: [Квартира](https://sergey70.github.io/FlatPlan/?layout=plan-2), [Санузел 1](https://sergey70.github.io/FlatPlan/?layout=bath-1). Старая ссылка `?layout=plan-1` перенаправляет к правому плану. Ссылка открывает соответствующий сохранённый вариант один раз; query-параметр затем убирается. Перед переключением сохраняйте нужные изменения отдельным вариантом.

## Первые действия

1. Переключайтесь между **3D** и **План**. Мышью вращайте 3D-вид, колесом меняйте масштаб; во вкладке **Варианты** доступны общий вид, вид сверху и ракурсы из комнат.
2. Выберите элемент на плане или через **Объекты → Поиск объектов**. Раскройте группу, чтобы выбрать отдельную деталь. Режим **Детали** позволяет выбирать вложенные части прямо в сцене.
3. Во вкладке **Свойства** задайте положение X/Y/Z, размеры, поворот, цвет и материал. Размеры учитывают масштаб родителей; координаты детали отсчитываются от родителя.
4. **Объекты → Добавить стену на план** создаёт стену высотой 2,70 м и включает её перемещение в 2D. Задайте длину, толщину, положение и угол. Удалять или скрывать можно любую незакреплённую стену.
5. В свойствах стены добавьте **Дверной проём** или **Окно**. Проём появится внутри стены в дереве; его положение, ширина, высота и уровень над полом редактируются независимо. Пересекающиеся или выходящие за стену проёмы отклоняются.
6. **Варианты → Сохранить как новый вариант** сохраняет всю сцену и ракурс. **Обновить «…»** заменяет выбранный сохранённый вариант текущей сценой. Текущая сцена сохраняется автоматически, а сохранённый вариант — отдельной кнопкой.

Кнопки отмены/повтора работают для редактирования, импорта и переключения вариантов. У пола доступны редактируемый внешний контур и отверстия. Стены, полы и предметы независимы: перенос стены не перестраивает комнаты автоматически. Нет проверки проходов и коллизий мебели.

**Срез стен** уменьшает высоту стен для обзора; потолочные светильники скрываются вместе с потолочным уровнем. В полном виде они остаются на записанной высоте. Для каждой стены режим среза можно отключить в её свойствах. Палитры, вечернее освещение, мебель, подписи и сетка переключаются во вкладке **Варианты**.

## Галерея интерьеров

[Отдельная галерея](https://sergey70.github.io/FlatPlan/?view=gallery) содержит **30 фотореалистичных изображений готового интерьера в 12 вариантах**: план квартиры и три схемы санузла × светлая, тёплая и контрастная отделка. Для каждой отделки квартиры — два ракурса кухни, спальня и комната 1; для каждого санузла — два внутренних ракурса. Изображения сгенерированы встроенным imagegen по соответствующим 3D-ракурсам исходного плана. В них показаны завершённая отделка, мебель, техника, текстиль и освещение. Дополнительно доступны 12 общих видов модели и четыре схемы.

Под каждым внутренним ракурсом можно переключить **Готовый интерьер / 3D-основа** и сравнить визуализацию с исходной геометрией. Генерация иллюстрирует материалы и внешний вид; точные размеры, проёмы и расстановка проверяются в модели и на схеме. Конкретные модели мебели и отделочных материалов ещё не выбраны. Галерея показывает базовый проект, личные правки посетителя в неё автоматически не попадают.

Выберите планировку и стиль в фильтрах. **Подробнее** открывает изображения, материалы и схему. Переключайте ракурсы миниатюрами или кнопками со стрелками; при фокусе внутри просмотра также работают клавиши ←/→, Home/End. Подпись показывает выбранный ракурс и его номер. **Открыть изображение целиком** открывает выбранную визуализацию или 3D-основу в исходном разрешении. **Сравнить** у двух карточек и нижняя кнопка **Сравнить два варианта** показывают их рядом; на телефоне — последовательно. Ракурсы и переключатели источника в сравнении работают независимо. Escape закрывает диалог. Если кадр не загрузился, нажмите **Повторить**, выберите другой ракурс или его 3D-основу. Просмотр галереи не меняет сохранённую сцену.

Галерея работает без WebGL и API-ключей. Изображения загружаются по мере прокрутки; при ошибке доступна кнопка **Повторить**. Происхождение изображений и воспроизведение описаны в [GALLERY_ASSETS.md](GALLERY_ASSETS.md).

## На телефоне

Модель расположена сверху, вкладки и прокручиваемые свойства — снизу. В 3D один палец вращает вид, два пальца меняют масштаб и положение камеры. Точные размеры вводятся в свойствах.

В режиме **План** один палец перемещает вид при включённом инструменте просмотра. Два пальца увеличивают и сдвигают план. Инструмент перемещения позволяет перетаскивать выбранный предмет; второе касание отменяет незавершённое перемещение. **Показать объект крупно** находит выбранный элемент.

## Сохранение, перенос и сброс

- **Файл → Скачать проект JSON** сохраняет текущую сцену и все варианты одним файлом.
- **Файл → Импортировать проект → Открыть проект** открывает JSON на другом устройстве. Восстанавливаются объекты, размеры, цвета, варианты и ракурс. Ошибка импорта оставляет текущий проект без изменений.
- **Файл → Сохранить текущий 3D-вид PNG** скачивает изображение.
- **Файл → Новый проект по файлу .plan → Создать заново** создаёт исходный проект с четырьмя вариантами. Это действие можно отменить в текущей вкладке.
- **Файл → Сбросить пользовательские данные → Сбросить безвозвратно** удаляет личные изменения, пользовательские варианты, имя и настройки вида в этом браузере. Откроется исходный правый план с четырьмя вариантами, очистятся история отмены и ожидающий импорт. Перед сбросом скачайте JSON, если нужна копия.

Сброс затрагивает только данные FlatPlan на текущем адресе. Скачанные файлы, другие сайты, устройства и локальный запуск независимы. В других открытых вкладках автосохранение приостановится: обновите страницу или выберите **Файл → Загрузить сохранённое в браузере**. **Продолжить с текущим проектом** явно сохранит старую сцену из той вкладки заново.

Изменения не отправляются в GitHub; облачной синхронизации нет. При конфликте вкладок, повреждении данных или ошибке записи редактор приостанавливает автосохранение и предлагает восстановление/экспорт. Если браузер запретил удаление, текущая сцена и история сохраняются.

Нужен Node.js 22.13+ (рекомендуется Node.js 24). Установите его с [nodejs.org](https://nodejs.org/), если команды недоступны.


Откройте **http://127.0.0.1:5173/** или **http://127.0.0.1:5173/?view=gallery**. Остановка — **Ctrl+C**. Для следующего запуска повторите `cd` и `npm run dev`.

## Проверка и сборка

```sh
cd /Users/belanovich-sy/Documents/github/flat_plan
npm run verify
npx playwright install chromium
npm run test:browser
```

`verify` проверяет геометрию, импорт, сохранение, варианты, историю, происхождение изображений, линтер, TypeScript и production-сборку. Браузерная проверка запускает сайт на порту 4188, использует изолированные desktop/mobile-контексты Chromium и останавливает сервер. Проверяются новый план, совместимость старых проектов, JSON, сохранение, сброс, манипуляции мышью/касаниями и галерея. Артефакты находятся в игнорируемой `.local/qa/`.

```sh
npm run preview
```

Ручной просмотр сборки — **http://127.0.0.1:4173/**, остановка — **Ctrl+C**. Готовый сайт находится в `dist/`.

## Обновление данных из исходного файла

Разовый конвертер читает конкретную структуру предоставленного Plan v3. Исходный файл хранится локально, в Git он не нужен.

```sh
python3 scripts/import-plan-source.py '/полный/путь/к/файлу.plan'
node scripts/export-gallery-plans.mjs
npm run build
node scripts/render-gallery.mjs
npm run verify
npm run test:browser
```

Команды обновляют анонимные геометрические данные, четыре SVG и 42 PNG модели с контрольными суммами. Фотореалистичные изображения обновляются отдельно через imagegen по новым модельным ракурсам; до этого проверка их происхождения обнаружит устаревшие ссылки на модель (см. GALLERY_ASSETS.md). Локальный реестр `.local/plan-source-identities.json` хранит соответствия идентификаторов и не публикуется. При первом переходе с прежнего экспорта передайте `--identity-source "/путь/к/предыдущему.plan"`; затем сохраняйте реестр для следующих запусков. Конвертер проверяет выбранную квартиру и отсутствие нераспределённых предметов; произвольный файл другого редактора или с иным количеством чертежей требует адаптации. Это не универсальный импорт `.plan` через интерфейс. Для обновления уже сохранённых проектов нужна отдельная ревизия миграции; не меняйте числовые данные молча.

## Публикация

GitHub Pages использует **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` запускает проверки и браузерные сценарии, затем публикует `dist/` при push в `main`. [Статус Actions](https://github.com/Sergey70/FlatPlan/actions).

Ресурсы работают в каталоге `/FlatPlan/` без внешних CDN. Репозиторий и исходная модель публичны; оригинальный файл, его идентификаторы и пользовательские сохранения в публикацию не входят.

## Структура

- `lib/plan-source.json`, `lib/plan-data.ts` — анонимные данные и типы.
- `lib/plan-project.ts`, `lib/plan-furniture.ts`, `lib/plan-refresh.ts` — четыре исходные сцены, сохранение прежнего проекта, условные модели предметов.
- `lib/editor-model.ts` — формат JSON версии 1, валидация, локальное хранение, история и варианты. Лимиты: 8 МБ на файл, 30 вариантов, 2500 элементов на сцену.
- `lib/editor-geometry.ts`, `lib/polygon-validation.ts` — общая геометрия 2D/3D, профили стен и проёмы.
- `lib/editor-scene.ts`, `app/editor.tsx` — Three.js, материалы, камера и интерфейс.
- `app/gallery.tsx`, `lib/gallery-data.ts`, `lib/gallery-shots.ts`, `public/gallery/gallery-012/`, `public/gallery/gallery-013/` — галерея, 3D-основы, готовые интерьеры и проверяемое происхождение; SVG по-прежнему в `public/gallery/plan-011/plans/`.
- `lib/apartment.ts`, `lib/editor-seed.ts` — историческая модель по фотографии и общие фабрики; сохранены для совместимости.
- `tests/plan-source.test.ts`, `tests/browser-source-plan.mjs` — соответствие файлу и сценарии нового плана.
- `lib/editor-webmcp.ts` — необязательный API браузера; обычная работа редактора его не требует.

## Если что-то не работает

- **Нет 3D:** откройте «План», обновите браузер и включите аппаратное ускорение. Нужен WebGL 2.
- **Изменение отклонено:** проверьте сообщение, закрепление объекта, границы проёмов и пересечения контуров.
- **Не сохраняется:** скачайте JSON, проверьте свободное место и разрешения на хранение данных сайта.
- **На другом устройстве исходный план:** импортируйте JSON; синхронизации нет.
- **Порт занят:** остановите прежний сервер или выполните `npm run dev -- --port 5174`.
- **Белый экран при открытии index.html:** запускайте через `npm run dev` или `npm run preview`.
- **Pages показывает старый сайт:** дождитесь зелёного deploy, проверьте регистр `/FlatPlan/` и обновите страницу.
- **Не запускаются браузерные проверки:** выполните `npx playwright install chromium`; на Linux — `npx playwright install --with-deps chromium`. Порт 4188 должен быть свободен.
