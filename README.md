# FlatPlan

Интерактивная демонстрационная квартира для браузера и GitHub Pages. Это пример площадью **63 м²**, а не обмерный план: кухня-гостиная, спальня, центральная прихожая и ванная. Пример нужен для выбора интерфейса и материалов; точная квартира будет добавлена позже.

Возможности: вращение и масштабирование 3D-модели, выбор комнаты, плоский план с размерами, срез стен, скрытие мебели и подписей, три палитры, дневной/вечерний свет. Кухня, сантехника, мебель и освещение моделируются в Three.js. Текстура дерева хранится в проекте. Состояние сбрасывается при перезагрузке; редактирования стен, импорта планов и сохранения расстановки пока нет.

## Быстрый запуск на Mac

Нужен Node.js **24 LTS** (поддерживается 22.13+). Если команды `node` и `npm` не найдены, установите LTS с https://nodejs.org/ и заново откройте Терминал.

Скопируйте в Терминал:

```sh
cd /Users/belanovich-sy/Documents/github/flat_plan
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173/**. Пока Терминал работает, сайт доступен локально. Для остановки нажмите **Ctrl+C** в этом Терминале. Следующий запуск: те же `cd` и `npm run dev`; повторять установку не нужно, пока не изменился lock-файл.

- Мышью: тяните для вращения, колесо для масштаба, правая кнопка для перемещения.
- На телефоне: один палец вращает, два пальца меняют масштаб и перемещают.
- Комнаты, материалы и кнопки доступны с клавиатуры. Кнопка сброса показывает всю квартиру.
- «План» открывает плоскую схему; она доступна и без WebGL 2.

## Проверка и сборка

```sh

```

Команда запускает тесты геометрических данных и валидации настроек, линтер, TypeScript и production-сборку. Готовый статический сайт находится в `dist/`.

Откройте **http://127.0.0.1:4173/**. Остановка — **Ctrl+C**. Сервер, база данных, ключи API и Cloudflare для опубликованного сайта не нужны.

## GitHub Pages

Подготовлен workflow `.github/workflows/pages.yml`. Он проверяет pull request, а при push в `main` или ручном запуске собирает и публикует `dist/`.

1. Отправьте проверенные файлы в репозиторий **Sergey70/FlatPlan**.
2. Откройте https://github.com/Sergey70/FlatPlan/settings/pages и выберите **Source → GitHub Actions**.
3. Откройте **Actions → Build and deploy FlatPlan → Run workflow → main → Run workflow**, если workflow ещё не запускался после настройки Pages.
4. Дождитесь зелёных `build` и `deploy`. Рабочая ссылка появится в результате `deploy` и в Settings → Pages; ожидаемый адрес — **https://sergey70.github.io/FlatPlan/**.

Репозиторий **Sergey70/FlatPlan** публичный; владелец открыл его для размещения демо. Публикация и доступность ожидаемого адреса считаются подтверждёнными только после успешного deploy. Обычный Pages-сайт общедоступен.

Ссылки: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [Vite static deploy](https://vite.dev/guide/static-deploy.html#github-pages). `base: './'` позволяет открывать сборку как в корне, так и в каталоге `/FlatPlan/` без внешних CDN.

## Где заменить демо

- `lib/apartment.ts` — названия, размеры комнат в метрах, общие размеры и палитры.
- `lib/apartment-scene.ts` — стены и проёмы, геометрия мебели, размещение, материалы и свет.
- `app/page.tsx` — интерфейс и схема 2D, включая условные обозначения мебели и проёмов.
- `public/textures/oak.jpg` — текстура дуба.

Для реальной квартиры нужно согласованно изменить данные комнат, стены/проёмы и мебель в 3D, затем схему 2D. Изменение одних чисел площади не перестраивает всю мебель автоматически. Новые размеры должны пройти тест отсутствия пересечений комнат. Чтобы начать, достаточно плана с размерами, высоты потолков и фотографий/референсов интерьера.

## Если что-то не работает

- **3D не появился:** откройте «План», обновите браузер и включите аппаратное ускорение. Three.js требует WebGL 2. Это не фотореалистичный трассировщик лучей; материалы и свет рассчитаны на интерактивный просмотр.
- **Порт занят:** остановите прежний запуск через Ctrl+C. Либо используйте `npm run dev -- --port 5174` и адрес, который напечатает Vite.
- **После открытия index.html двойным кликом белый экран:** используйте `npm run dev` или `npm run preview`; ES-модули должны загружаться через HTTP.
- **Pages показывает 404:** проверьте Source → GitHub Actions, успешный deploy и точный регистр `/FlatPlan/`. Дайте GitHub время обновить публикацию.
- **Deploy сообщает об отсутствии Pages:** сначала настройте Pages в репозитории и проверьте, позволяет ли тариф публикацию из приватного репозитория.
- **Проверка npm завершилась ошибкой:** убедитесь, что Node соответствует версии выше, затем выполните `npm ci` и повторите `npm run verify`.
