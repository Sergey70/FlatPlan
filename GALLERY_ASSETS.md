# Изображения галереи — GALLERY-012

Коллекция содержит **42 PNG в 12 вариантах**: четыре чертежа из предоставленного `.plan` × три палитры редактора (`natural`, `warm`, `contrast`). Для каждой отделки квартиры есть пять изображений: кухня с диваном, кухня в сторону окна и телевизора, спальня, комната 1 и общий вид. Для каждой отделки каждого санузла — три: вид от входа, раковина и оборудование, общий вид. Используется правый план квартиры (21,43 м² — кухня, 13,55 м² — спальня) и три отдельные схемы санузла.

Данные: `lib/plan-source.json`, ревизия **PLAN-011**. Построение сцены: `lib/plan-project.ts` и `lib/plan-furniture.ts`. Изображения создаются общим с редактором Three.js-рендерером и PNG-экспортом. Камеры, угол обзора и подписи заданы в `lib/gallery-shots.ts`. Интерьерные камеры стоят внутри соответствующих комнат на высоте 1,55 м; стены, окна, двери, светильники и мебель сохраняют полную высоту. Потолок для этих кадров построен по контурам помещений на известной высоте 2,70 м и не добавляется в пользовательские сцены. Общий вид использует срез стен. Сетка и подписи скрыты.

Файлы: `public/gallery/gallery-012/images/<план>-<палитра>-<ракурс>.png` (**1800 × 1200**). Соответствующие схемы: `public/gallery/plan-011/plans/<план>.svg` (1000 × 1000). Ревизия галереи отделена от ревизии плана: обновление изображений не запускает миграцию личных проектов. Предыдущие изображения PLAN-011 остаются доступны по прежним адресам.

`public/gallery/gallery-012/manifest.json` связывает каждый кадр с исходной ревизией, SHA-256 сцены, палитрой, камерой, углом обзора, режимом стен, высотой потолка, размером и SHA-256 PNG. Перед экспортом генератор сравнивает сцену в браузере с канонической моделью. Для переносимости сравнения и контрольных сумм между процессорами числа сериализуются с семью десятичными знаками; сама геометрия не округляется. Тесты обнаруживают устаревшие кадры при изменении сцены или камеры и проверяют, что камеры находятся внутри нужных комнат, вне предметов мебели.

## Воспроизведение

```sh
cd /Users/belanovich-sy/Documents/github/flat_plan
npm ci
npx playwright install chromium
node scripts/export-gallery-plans.mjs
node scripts/render-gallery.mjs
npm run verify
npm run test:browser
```

Генератор запускает локальный Vite на порту 4189 и закрывает его после завершения, включая ошибку. Ручная остановка — Ctrl+C. Страница `scripts/gallery-render.html` предназначена только для локальной генерации и не входит в production-сборку. Для уже запущенного Vite можно задать `FLATPLAN_RENDER_URL=http://127.0.0.1:5173/`; это должен быть dev-сервер, не preview.

Для проверки одной отделки используйте `FLATPLAN_RENDER_CONCEPT=plan-2-warm node scripts/render-gallery.mjs`: такая проба не перезаписывает полный манифест. Перед публикацией обязательно повторите полную генерацию и проверки. Версии Chromium/GPU могут влиять на пиксели, поэтому новая генерация обновляет манифест.

Если порт занят, завершите предыдущий dev-сервер или укажите его URL. Если Chromium не установлен, повторите `npx playwright install chromium`. Если проверка происхождения изображений не проходит после изменения модели или камеры, повторите полную генерацию; не редактируйте контрольные суммы вручную. Отсутствующая текстура или ошибка страницы останавливают генерацию.

Габариты и расположение предметов соответствуют числовым данным. Мебель, сантехника и техника представлены условными моделями: в исходном файле нет готовых детальных 3D-мешей. Материалы и освещение иллюстративные; это не фотографии и не автоматически обновляемые изображения личной сцены посетителя.

Исходный `.plan`, номер проекта и содержимое пользовательских сохранений не входят в галерею. Текстура дерева описана в README.
