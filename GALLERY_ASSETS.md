# Изображения галереи — ROOM-014

## Комната с рабочим местом

Три новых готовых кадра комнаты находятся в `public/gallery/gallery-014/finished/plan-2-<отделка>-room.png`. Точная 3D-основа комнаты и обновлённые общие виды — шесть PNG в `gallery-014/images/`. Схема предложения — `gallery-014/plans/plan-2.svg`, редактируемый проект — `gallery-014/room-workspace.json`.

`lib/room-proposal.ts` создаёт отдельное предложение поверх PLAN-011: сохраняет стены, проёмы, кровать 90 × 200 см, тумбу и все остальные помещения; заменяет четыре предмета комнаты столом 160 × 70 см, правильно ориентированным рабочим креслом, двумя 27-дюймовыми мониторами, системным блоком, клавиатурой и мышью. Экраны перпендикулярны остеклению, свет приходит сбоку. Дополнительная проверка подтверждает свободную полосу более метра за креслом и отсутствие мебели у дверных проёмов. Это проверка предлагаемой геометрии, не светотехнический расчёт прямого солнца.

Тёплый кадр сгенерирован встроенным imagegen по новому 3D-ракурсу с прежним готовым интерьером как референсом отделки. Светлая и контрастная версии сохраняют принятую расстановку. `gallery-014/prompts.json` хранит фактические запросы и проверки всех текущих 30 готовых кадров; неизменённые 27 записей и файлы сохранены из GALLERY-013. `gallery-014/manifest.json` описывает все текущие 42 модельных ракурса: шесть новых используют предложение, остальные 36 сохраняют исходные PNG и сцены GALLERY-012. Для ракурсов других комнат мебель предложения находится вне видимости и не меняет их исходные сцены. `gallery-014/finished-manifest.json` связывает актуальные готовые кадры с их модельными основами, запросами и референсами. Старые файлы и URL сохранены.

Ревизия источника остаётся PLAN-011; автоматической миграции сохранений нет. JSON предложения содержит отдельный активный вариант и четыре исходных варианта. Скачивание, импорт, запуск, остановка и устранение ошибок описаны в README. Для обновления выполните экспорт схем, рендер моделей, генерацию/визуальную проверку новых готовых изображений и запись происхождения командами ниже. Скрипт рендера проверяет хеши и параметры повторно используемых исходных кадров перед включением их в новый манифест.

## Исходная коллекция GALLERY-013

Коллекция содержит **30 фотореалистичных изображений готового интерьера**, сгенерированных встроенным imagegen, и **12 общих видов 3D-модели**. Всего 12 вариантов: правый план квартиры и три отдельные схемы санузла из предоставленного `.plan` × три отделки (`natural`, `warm`, `contrast`). Для каждой отделки квартиры есть четыре готовых интерьера: кухня с диваном, кухня в сторону окна и телевизора, спальня и комната 1. Для каждого санузла — два внутренних ракурса. Дополнительно у каждого варианта есть общий вид и соответствующая схема.

Основные изображения — результат генерации законченной отделки по точным модельным ракурсам. В галерее у каждого из 30 внутренних кадров есть переключатель **Готовый интерьер / 3D-основа**. Светлая отделка использует светлый дуб, белые стены, светлый камень и нержавеющий металл; тёплая — медовый дуб, бежевые оттенки и бронзу; контрастная — тёмный орех, светло-серые стены, графитовый текстиль и чёрный металл. В санузлах стены и пол отделаны керамогранитом под камень.

Генерация использует геометрию и ракурс как визуальный контроль. При проверке сопоставляются положение окон, дверей, стен, мебели и оборудования; внешний вид конкретных изделий, мелкие детали, свет и вид за окном иллюстративные. AI-изображение не является размерным чертежом: точные координаты и габариты доступны в 3D-основе и схеме. Личные изменения посетителя не перегенерируют опубликованные изображения.

## Сгенерированные готовые интерьеры

Файлы: `public/gallery/gallery-013/images/<план>-<отделка>-<ракурс>.png` (**1536 × 1024**). Оригинальные PNG сохранены без постобработки. `prompts.json` в том же каталоге содержит фактически использованный полный запрос, относительные адреса референсов и результат визуальной проверки каждого кадра. Сначала создана тёплая кухня по модельному ракурсу, затем остальные помещения в согласованной отделке; светлая и контрастная отделки меняют материалы соответствующего готового кадра. Для каждого файла используется отдельная генерация, без коллажей и повторного использования одной картинки для разных помещений. Для уточнённых кадров массив `steps` хранит последовательность фактических запросов и референсов. Пять вспомогательных PNG с префиксом `reference-` сохраняют входы таких правок и не показываются как отдельные варианты галереи.

`manifest.json` связывает все 30 результатов с контрольными суммами PNG, запроса, использованных изображений-референсов, соответствующего модельного ракурса и канонической сцены PLAN-011. Это проверка происхождения и актуальности, а не автоматическое доказательство геометрической точности AI-пикселей. Визуальная проверка остаётся обязательной.

Для обновления изображений используйте встроенный imagegen с запросами из `prompts.json` и указанными референсами, предварительно открыв их для просмотра. При изменении геометрии сначала обновите 3D-ракурсы. Проверьте каждый результат, при необходимости повторите генерацию с конкретной правкой, затем сохраните принятый PNG и фактический запрос. Результат генерации недетерминирован; побайтовое повторение не гарантируется. CLI-скрипт ниже только записывает контрольные суммы уже готовых и проверенных изображений:

```sh
cd /Users/belanovich-sy/Documents/github/flat_plan
node scripts/record-gallery-finishes.mjs
npm run verify
npm run test:browser
```

Галерея в опубликованном сайте использует статические файлы, без API и ключей посетителя. Если проверка обнаружила отсутствующий PNG, изменённый референс или запрос, восстановите соответствие и визуально проверьте результат; не меняйте хеши вручную.

## Точные 3D-основы — GALLERY-012

Данные: `lib/plan-source.json`, ревизия **PLAN-011**. Построение сцены: `lib/plan-project.ts` и `lib/plan-furniture.ts`. Изображения создаются общим с редактором Three.js-рендерером и PNG-экспортом. Камеры, угол обзора и подписи заданы в `lib/gallery-shots.ts`. Интерьерные камеры стоят внутри соответствующих комнат на высоте 1,55 м; стены, окна, двери, светильники и мебель сохраняют полную высоту. Потолок для этих кадров построен по контурам помещений на известной высоте 2,70 м и не добавляется в пользовательские сцены. Общий вид использует срез стен. Сетка и подписи скрыты.

Файлы: `public/gallery/gallery-012/images/<план>-<палитра>-<ракурс>.png` (**1800 × 1200**). Соответствующие схемы: `public/gallery/plan-011/plans/<план>.svg` (1000 × 1000). Ревизия галереи отделена от ревизии плана: обновление изображений не запускает миграцию личных проектов. Предыдущие изображения PLAN-011 остаются доступны по прежним адресам.

`public/gallery/gallery-012/manifest.json` связывает каждый кадр с исходной ревизией, SHA-256 сцены, палитрой, камерой, углом обзора, режимом стен, высотой потолка, размером и SHA-256 PNG. Перед экспортом генератор сравнивает сцену в браузере с канонической моделью. Для переносимости сравнения и контрольных сумм между процессорами числа сериализуются с семью десятичными знаками; сама геометрия не округляется. Тесты обнаруживают устаревшие кадры при изменении сцены или камеры и проверяют, что камеры находятся внутри нужных комнат, вне предметов мебели.

## Воспроизведение 3D-основ

```sh
cd /Users/belanovich-sy/Documents/github/flat_plan
npm ci
npx playwright install chromium
node scripts/export-gallery-plans.mjs
node scripts/render-gallery.mjs
npm run verify
npm run test:browser
```

Генератор запускает локальный Vite на порту 4189 и закрывает его после завершения, включая ошибку. Ручная остановка — Ctrl+C. Страница `scripts/gallery-render.html` предназначена только для локальной генерации и не входит в production-сборку. Для уже запущенного Vite можно задать `FLATPLAN_RENDER_URL=http://127.0.0.1:5173/`; это должен быть dev-сервер, не preview.

Для проверки одной отделки используйте `FLATPLAN_RENDER_CONCEPT=plan-2-warm node scripts/render-gallery.mjs`: такая проба не перезаписывает полный манифест. После изменения модели повторите полную генерацию 3D-основ, обновите соответствующие готовые интерьеры и выполните проверки перед публикацией. Версии Chromium/GPU могут влиять на пиксели, поэтому новая генерация обновляет манифест.

Если порт занят, завершите предыдущий dev-сервер или укажите его URL. Если Chromium не установлен, повторите `npx playwright install chromium`. Если проверка происхождения изображений не проходит после изменения модели или камеры, повторите полную генерацию; не редактируйте контрольные суммы вручную. Отсутствующая текстура или ошибка страницы останавливают генерацию.

В 3D-основах габариты и расположение предметов соответствуют числовым данным. Мебель, сантехника и техника представлены условными моделями: в исходном файле нет готовых детальных 3D-мешей. Материалы и освещение иллюстративные; это не фотографии и не автоматически обновляемые изображения личной сцены посетителя.

Исходный `.plan`, номер проекта и содержимое пользовательских сохранений не входят в галерею. Текстура дерева описана в README.
